## Rules

- Match the user's colorway to one row exactly or by an unambiguous spelling variant.
- For one-colorway ecommerce, inspect only that folder's three stock angles.
- For multi-cap scenes, select additional official colorways only from this table unless custom mockups were explicitly requested.
- Never describe White/Black, White/Forest Green, White/Navy, White/Red, White/Royal, Khaki/Forest Green, or any other absent combination as official stock in this package.

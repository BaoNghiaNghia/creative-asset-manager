# Etsy Spy Picked — C1717 ColorMatch V5

## Scope

- Scope is every eligible Picked listing with completed extracted designs and a
  readable, SHA-verified PNG thumbnail; one ranking per individual design SHA.
- Preview-only garment color advice, not design regeneration, proof of stock, or
  a print authorization. Native PNG and Google Drive original remain immutable.
- SMS C1717 catalog snapshot 2026-11-14: 72 colorways; 56 set up; 54 have
  valid HEX; 16 supplier-only. Three missing HEX swatches are disabled.
- Demand prior is a **coarse ranking** from SMS C1717 per-color units/week,
  trailing 60 days as of 2026-11-14. It is not live, not the restricted
  SMS Best sellers report and not market-wide sales. No customer data is stored.
- Rank order is dominated by **each artwork's pixel contrast and legibility**;
  demand serves only as a tie-breaker. Prefer perceptual diversity.
  Aim for 7–10 unique readable backgrounds per design. If fewer than 7 clear the
  safety threshold, store the smaller honest result with
  `insufficient_safe_colors: true`; do not invent bad options.
- Method: `thumbnail_pixel_contrast_sales_prior`; algorithm:
  `colormatch-sms-c1717-v5`.
- V1–V4 cached records remain readable; the new full backfill replaces stale
  metadata only when the artwork SHA still matches.

## Safe rollout / backfill

1. Build and publish the scoped source and committed frontend dist from the
   verified **main** commit. Keep current + rollback; verify `/version`
   and frontend build provenance.
2. Verify active backend imports V5 before touching Picked metadata.
   The wrapper rejects outdated backend releases and running it without
   `--apply` performs a read-only dry-run.
3. From an authorized production shell (not this source worktree), execute:

   ```bash
   sudo /opt/creative-asset-manager/current/scripts/cam-etsy-colormatch-v2-backfill.sh --tenant-id creative-assets-prod --page-size 100
   sudo /opt/creative-asset-manager/current/scripts/cam-etsy-colormatch-v2-backfill.sh --tenant-id creative-assets-prod --page-size 100 --delay-seconds 0.5 --apply
   ```

4. Confirm `scanned_jobs`, `already_current`, `targets_drive`,
   `targets_local`, `updated_drive`, `updated_local`,
   `unavailable_or_mismatch`, `skipped`, `errors`.
   Inspect Picked multi-placement listings and check 7–10 suggested swatches
   for each valid design (not merely a static list for the listing).
5. The backfill is resume-safe/idempotent; it locks and rechecks Picked,
   job completion, SHA and the private Drive thumbnail before each
   `color_match` JSON update. It **never** changes master PNG bytes.
   Design outputs without available valid thumbnails are reported as
   unavailable; they are not regenerated by this job.

If main production access is unavailable, retain the source branch; do not claim
the rollout or full backfill completed.
